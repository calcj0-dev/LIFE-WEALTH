# LIFE & WEALTH ロードマップ

2026-10-19 作成。ルールは [design.md](design.md)、要件は [requirements.md](requirements.md) を参照。

プロトタイプは段階に分けて作る（段階3のあと、遊びを作り直す段階3.5を入れた）。各段階の終わりに確認し、問題なければコミットして次に進む。

## 見積もりの見方

- **作業(h)**: Claude が作る時間の目安。やりとりの回数や作り直しで前後する
- **確認(h)**: あなたが遊んだり、内容を確かめたりする時間の目安
- 進んだら `- [ ]` を `- [x]` に変え、実績欄に実際の時間やメモを書く

## バージョンの管理

バージョンは「大.中.小」の3つの数字で表す。0.1.0 から始め、公開時に 1.0.0 にする。

| 数字 | 上げるとき | 例 |
| --- | --- | --- |
| 大 | 公開したとき（以後は大きな作り直しのとき） | 0.9.0 → 1.0.0 |
| 中 | 段階が1つ終わったとき（公開後は機能を追加したとき） | 0.2.0 → 0.3.0 |
| 小 | 不具合の修正や、数値の調整をしたとき | 0.3.0 → 0.3.1 |

| バージョン | 内容 |
| --- | --- |
| 0.1.0 | 設計書がそろった状態（開発前） |
| 0.2.0 | 段階1（土台）が終わった |
| 0.3.0 | 段階2（最小限で遊べる）が終わった |
| 0.4.0 | 段階3（中身を全部入れる）が終わった |
| 0.5.0 | 段階3.5（遊びの作り直し）が終わった |
| 0.6.0 | 段階3.6（遊んで気になったところを直す）が終わった |
| 0.7.0 | 段階3.7（ニュースと年末の見直し）が終わった |
| 0.8.0 | 段階4（CPU のライバル）が終わった |
| 0.9.0 | 段階5（見た目を整える）が終わった |
| 1.0.0 | 公開した |

- バージョンは package.json に書き、上げるたびに GitHub にも同じ名前の印（タグ、例: v0.2.0）を付ける
- タイトル画面の右上に、今のバージョンを表示する（package.json から自動で読む）
- 何が変わったかは [CHANGELOG.md](../CHANGELOG.md) に書く
