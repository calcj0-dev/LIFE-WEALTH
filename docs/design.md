# LIFE & WEALTH ゲーム設計書（たたき台）

2026-10-18 時点。前提は [requirements.md](requirements.md) を参照。

この設計書は、プロトタイプを作るためのルールと数値を決めるものです。「（仮）」が付いた数値は遊びやすさを優先した仮の値で、あとで統計データや遊んだ感触で見直します。

数値の決め方:

- 設計書で決まっていない数値は、Claude が現実の水準に合わせて仮に決め、段階1の報告でまとめて確認する
- 数値は細かくしすぎず、中途半端な値にしない。金額は「10万円」「50万円」「300万円」のような区切りのよい値、割合は「5%」「10%」のような値にする

## 1. ゲームの全体像

- 1人用。22歳で社会に出て、65歳を迎えた時点の幸福度で評価する（9章）
- 1ターン＝1年、全44ターン（22歳〜65歳）
- 毎年ルーレットで盤面を進み、止まったマスの出来事に対応しながら、収入を貯金・投資・ローン返済に振り分ける
- 税金や NISA などの制度は扱わない。収入はすべて手取りとして扱う

```
タイトル → ルーレットで職業が決まる → スタート時の家計を確認 → 投資方針を決める → 毎年のターン × 44 → 65歳で終了 → 結果画面
```

## 2. 1ターンの流れ

| 順番 | フェーズ | 内容 |
| --- | --- | --- |
| 1 | 年初 | 年齢が1つ上がる。その年の政治・経済のイベントが1つ起き（7章）、景気と各資産の価格が更新される。その年の収入と支出の予定（職業の固定費、生活費、教育費、ローン返済、保険料など）を知らせる |
| 2 | 移動 | ルーレット（1〜6）を回し、出た数だけ進む |
| 3 | マス | 止まったマスの出来事が起きる（選択肢があれば選ぶ） |
| 4 | 年末決算 | 1年分の収入と支出をまとめて計算し、銀行預金に反映する。余ったお金を投資方針（6.3）どおりに自動で配分する |

### 2.1 売買（いつでもできる）

- 売買は決まったフェーズではなく、画面の「資産運用」ボタンからいつでもできる。押さなければ売買せずに次の年へ進む
- 対象: 債券・ゴールド・投資信託・株式の売買、不動産の売却、ローンの繰り上げ返済、保険の解約（加入は保険マスでだけ）
- 考える時間でゲームが長くならないように、次の工夫をする
  - 投資方針: ゲームの最初に決めた配分どおりに、毎年自動で買われる（6.3）
  - かんたん操作: 「10万円買う」「半分売る」「全部売る」などのボタンで、数字の入力を減らす
  - 大事な年だけ知らせる: 暴落や急騰の年だけ「投資を見直しますか？」と表示する
- 目標は1年あたり平均40秒、1プレイ約30分。プロトタイプで実際の時間を測って調整する

### 2.2 テンポ

- 「OK」だけの出来事（選択肢のない出来事）は画面を止めず、お金と幸福ポイントの増減を浮かび上がる表示で知らせて、そのまま進む
- 年末決算は、ふつうの年は短い表示（純資産と幸福ポイントの増減）にし、「詳しく見る」で内訳を開く。借金をした年や、純資産が大きく動いた年は、はじめから詳しく表示する

年末決算の計算:

```
銀行預金 ＝ 銀行預金
      ＋ 給料（手取り）＋ 配偶者の給料 ＋ 利息 ＋ 配当 ＋ 家賃収入
      − 職業の固定費 − 生活費 − 教育費 − 保育料 − ローン返済 − 不動産の経費 − 保険料
```

ルーレットは出目を決める部分と見た目を分けて作り、あとでサイコロ（1〜6）に差し替えられるようにする。

## 3. 盤面

盤面は1周72マスのループ型にする。1回に平均3.5マス進むので、約21年で1周し、65歳までに約2周する。同じマスに止まることが少なく、人生の道のりを進んでいく感覚を重視する。

ループ型にする理由: 「1ターン＝1年」と「ルーレットで進む」を両立させるため。一本道だと、出目しだいで65歳より前にゴールに着いたり、着かなかったりしてしまう。人生の段階は盤面の位置ではなく年齢で表す（ライフイベントは年齢に合ったものだけが起きる）。

### 3.1 見せ方

- 人生ゲームを参考に、色とりどりのマスが曲がりくねった1本の道に並び、道のまわりに家や木などが置かれた、にぎやかな盤面にする
- マスには種類ごとの色とアイコンを付ける
- 盤面全体は一度に表示せず、駒の周りを拡大して映し、駒の移動に合わせて画面が動く
- 盤面の全体図はボタンで表示できる
- 見た目は参考にとどめ、盤面やマスのデザイン、キャラクターは独自のものにする。ゲームの中で「人生ゲーム」という言葉は使わない

### 3.2 拡張できる作り

- 盤面は「マスの一覧」と「マス同士のつながり」をデータファイルで持ち、コードを変えずにマス数や配置を変えられるようにする
- 各マスは、種類、地図上の位置、次のマス（複数可）を持つ。今回は一本のループだが、将来は分かれ道（どちらに進むか選ぶ）や、エリアの追加にも対応できる形にしておく
- マスの種類ごとの数も、データファイルで調整できるようにする

### 3.3 マスの内訳（仮）

| マスの種類 | 数 | 内容 |
| --- | --- | --- |
| スタート | 1 | 通過すると、その周回で起きたことの振り返りを表示 |
| ストップ（結婚） | 1 | 出目が残っていても必ず止まる。結婚するかどうかを選ぶ（3.4） |
| ライフイベント | 24 | 年齢や家族の状態に合ったイベントを1つ引く（5章） |
| 良い出来事 | 17 | 臨時収入、昇給のチャンスなど |
| 保険 | 3 | 医療保険、火災・地震保険に入るかどうかを選ぶ（3.6） |
| 悪い出来事 | 13 | 突然の出費、収入減など |
| ギャンブル | 3 | 宝くじ・競馬・パチンコに賭けるか、賭けないかを選ぶ（3.5） |
| 不動産 | 10 | 売り出し中の物件が出て、自宅として買う／投資用に買う／見送るを選ぶ（6.2） |
| 合計 | 72 | |

政治・経済の出来事はマスではなく、毎年の年初に共通で起きる（7章）。

### 3.4 ストップマス

- 出目が残っていても、通りかかったら必ずそこで止まるマス。大事な選択を、運に左右されずに必ず体験させるために使う
- マスの種類の一つとしてデータで持ち、将来は住宅購入や老後の準備など、ほかの選択にも使えるようにする
- 結婚ストップはスタートから約18マス先に置く。多くの場合、26〜28歳ごろに止まる

結婚ストップのルール:

| 状況 | 起きること |
| --- | --- |
| 1周目に止まる | 結婚する／しないを選ぶ。結婚する場合は、結婚式の費用の大小と、配偶者の働き方（共働き／片働き、4.5）も選ぶ |
| 1周目で断り、2周目に止まる | もう一度、結婚する／しないを選べる |
| 1周目で結婚済みで、2周目に止まる | 今回は何も起きない（将来、別の出来事を入れる候補） |

2周目に止まるのは47〜49歳ごろなので、2周目に結婚した場合は出産の条件（45歳まで）に当てはまらず、子どもは持てない。これは仕様とする。

### 3.5 ギャンブルマス

- 止まると、宝くじ・競馬・パチンコのどれかに賭けるか、賭けないかを選ぶ
- 賭ける金額はプレイヤーが選ぶ（例: 1万円、10万円、100万円）
- 戻ってくる金額の平均は、現実の還元率どおりにする。長く続けるほど損をすることを、体験から学べるようにする

| 種類 | 還元率（概算、要確認） | 結果の出方 |
| --- | --- | --- |
| 宝くじ | 約45% | ほとんどは外れるか少額。ごくまれに大当たり |
| 競馬 | 約75% | 当たる確率と配当の大きさが、選ぶ買い方で変わる |
| パチンコ | 未確認（公的な数字がない） | 勝ち負けの幅が中くらいで、短期では勝つこともある |

- 還元率の数値は、金額の調査のときに出典を確認して決める
- 結果画面に、ギャンブルに使った金額と戻った金額の合計を表示する
- ギャンブルマスを設定で外す機能は設けない。全員がギャンブルマスありで遊ぶ
- 将来ストアに出す場合、疑似ギャンブルで年齢制限が上がる可能性がある。各ストアの規約を確認する

### 3.6 保険マス

- 止まると、医療保険と火災・地震保険のそれぞれについて、入るかどうかを選ぶ（4.4）
- すでに入っている保険は、そのまま続けるか解約するかを選べる
- 3マスなので、1周目（約21年）のうちに止まるのはおよそ6割の人。早く止まれば、医療保険に安い保険料で入れる。止まれないまま年を取るリスクも、ゲームの一部とする

## 4. プレイヤー

### 4.1 職業（スタート時にルーレットで決まる）

職業は自分で選ばず、ゲームの始めにルーレットで決まる。6つの職業は同じ確率（6分の1ずつ）。職業によって、毎年の収入と、職業の固定費が決まる。

| 職業 | 初任給（手取り・年、仮） | 昇給（年、仮） | 職業の固定費（年、仮） | 収入の安定性 | 特徴 |
| --- | --- | --- | --- | --- | --- |
| 会社員 | 300万円 | ＋1.5% | 10万円（通勤・スーツなど） | 中 | 標準的 |
| 公務員 | 280万円 | ＋1% | 10万円（通勤など） | 高（失業なし） | 安定しているが伸びは小さい |
| ITエンジニア | 340万円 | ＋2% | 20万円（勉強・機材など） | 中 | 伸びは大きいが、転職や失業の出来事が起きやすい |
| スポーツ選手 | 500万円 | 活躍しだいで大きく上下 | 100万円（トレーニング・遠征・体のケアなど） | 低 | 若いうちは高収入。35歳前後で引退し、別の仕事に移る。けがのリスクが高い |
| YouTuber | 150万円 | 毎年大きく上下 | 30万円（撮影機材・編集ソフトなど） | 低 | 収入の振れ幅が最も大きい。まれに大ヒットで収入が急増する |
| フリーター | 200万円 | ＋0.5% | 0万円 | 中 | 収入は低いが、転職がしやすく、時間の自由がある |

- 職業の固定費は、転職すると新しい職業のものに変わる。数値はあとで調整する
- 職業が決まったら、スタート時の家計（年収、職業の固定費、生活費、1年の支出の合計、1年で残る見込みのお金）を表示する

- スタート時の銀行預金: 50万円（仮）
- スタート時の住まいは全員賃貸
- 60歳以降の給料は60歳時点の60%（仮）。年金は扱わない
- スポーツ選手の引退後や、YouTuber・フリーターからの転職先は、ライフイベントの「転職」で選ぶ

### 4.2 生活費（仮）

| 家族構成 | 生活費（年） |
| --- | --- |
| 単身 | 160万円 |
| 夫婦 | 260万円 |
| 子ども1人ごと | ＋50万円（教育費は別） |
| 持ち家 | 家賃分として −60万円（住宅ローン返済は別） |

- 生活費は、物価に合わせて上がる。物価は毎年1%ずつ上がり、さらに「物価上昇」のニュースの年は5%上がる（7章）

### 4.3 プレイヤーが持つ情報

年齢、職業、給料、銀行預金、家族（配偶者の有無と働き方、子どもの人数と年齢）、住まい（賃貸／持ち家）、保有している株式・投資信託・不動産、ローン、加入している保険、これまでの出来事の記録。

### 4.4 保険

保険は「起きる確率は低いが、起きると家計が大きく傾く出来事」に備えるものとして扱う。平均すると払った保険料より戻るお金の方が少ない（保険会社の経費の分）ことと、それでも大きな損失を防げることの両方を体験させる。

| 保険 | 保険料（年、仮） | 備える出来事 | 支払われるお金 |
| --- | --- | --- | --- |
| 医療保険 | 加入した年齢で決まる。22歳なら3万円、以後1歳上がるごとに＋0.2万円 | 病気・けが | 治療費の全額 |
| 火災・地震保険 | 物件1つにつき3万円 | 火事、地震などの災害（悪い出来事マス） | 修理費や損害の全額 |

- 保険には、保険マスに止まったときだけ入れる（3.6）。解約は「資産運用」ボタンからいつでもできる
- 医療保険は、若いうちに入るほど保険料が安い。年を取ってから入ると高くなる
- 住宅ローンで自宅や投資用の物件を買うと、その物件の火災・地震保険には自動で入る（現実の住宅ローンと同じ）
- 貯金が十分にあれば、保険に入らず自分で備える選択もありうる。結果画面で、払った保険料の合計と、受け取ったお金の合計を表示する
- 生命保険は入れない。このゲームでは本人の死亡を扱わないため
- 保険料は年末決算で引く。幸福度は増減しない

### 4.5 配偶者の働き方

結婚するときに、配偶者の働き方を選ぶ。

| 選択 | 配偶者の収入（手取り・年、仮） | 家計への影響 |
| --- | --- | --- |
| 共働き | 280万円から始まり、毎年＋1.5% | 世帯の収入が増える。子どもが小さいうち（0〜5歳）は保育料がかかる（未調査） |
| 片働き（配偶者は家庭に専念） | なし | 収入は増えない。保育料はかからない |

- 共働きで出産したときは、「育休のあと仕事に戻る」（出産した年だけ配偶者の収入が半分）か、「仕事を辞めて家庭に専念する」（片働きに切り替わる）かを選ぶ
- 片働きの家庭には、ライフイベントのマスで「配偶者の再就職」が起きることがある（5.1）
- 配偶者の年齢は本人と同じとして扱う。60歳になる年に、配偶者の収入も60%になる
- 共働きと片働きで、幸福ポイントに差はつけない。働き方の良し悪しを押しつけないため、違いはお金の面だけにする

## 5. ライフイベント

ライフイベントは2種類ある。

- **マスで起きるイベント（5.1）**: ライフイベントのマスに止まると、条件に合うものから1つが選ばれる
- **年齢や状況で自動的に起きるイベント（5.2）**: マスに関係なく、条件を満たした年の年初に起きる

金額は未調査なので「未調査」または「（仮）」とする。幸福ポイントは、小＝3、中＝5、大＝10、特大＝15を目安にし、自動で何千回も遊ばせて釣り合いを調整する。幸福の源は家族だけに偏らないよう、旅行・趣味・学び・仕事・人とのつながりにも広く置く。

### 5.1 マスで起きるイベント

| イベント | 起きる条件 | プレイヤーの選択 | お金 | 幸福ポイント |
| --- | --- | --- | --- | --- |
| 出産 | 結婚している、子ども3人未満、45歳まで | 子どもを迎える／今は見送る。共働きなら、配偶者が育休のあと仕事に戻るか、辞めるかも選ぶ（4.5） | 出産費用（未調査）。以後、生活費と教育費が増える | 迎える: ＋15 |
| 配偶者の再就職 | 結婚していて片働き、60歳まで | 働きに出る／今のまま | 働きに出ると、配偶者の収入が年100万円（パートの水準、仮） | なし |
| 転職 | 55歳まで（年齢の下限なし） | 転職する／しない。転職先は職業の一覧から選ぶ（スポーツ選手を除く） | 新しい職業の給料になる（その職業の同年代の水準、仮） | 転職する: ＋3 |
| 昇進 | 会社員・公務員・ITエンジニア | なし | 給料が＋10%（仮） | ＋5 |
| 失業 | 公務員以外。職業ごとの失業リスクで起きやすさが変わる | なし | 1年間、給料なし。復帰後の給料は元の90%（仮） | −10 |
| 病気・けが | 誰でも。年齢が上がるほど起きやすい | なし | 治療費（未調査）。重い場合は1年間働けない。医療保険に入っていれば治療費は全額支払われる（4.4） | −5 |
| 介護 | 50歳以上 | 施設に任せる／自宅で介護する | 施設: 費用が大きい。自宅: 費用は小さいが、その年の給料が減る（未調査） | どちらも −5 |
| 旅行 | 誰でも | 海外旅行／国内旅行／行かない | 海外 50万円、国内 15万円（仮） | 海外 ＋10、国内 ＋5 |
| 趣味 | 誰でも | 本格的に始める／見送る | 始めるとき 30万円、以後毎年 10万円（仮） | 始めた年 ＋8、続けている間は毎年 ＋2 |
| 学び直し・資格 | 50歳まで | 学ぶ／見送る | 30万円（仮） | 学ぶ: ＋3、給料が＋5%（仮） |
| 副業・起業 | 25〜55歳 | 挑戦する／見送る | 元手 100万円（仮）。成功すると毎年の収入が増え、失敗すると元手を失う | 成功 ＋10、失敗 −5 |
| 人とのつながり | 誰でも | 参加する／しない（同窓会、地域の活動など） | 5万円（仮） | 参加する: ＋3 |
| ペットを迎える | 誰でも | 迎える／見送る | 迎えるとき 20万円、以後毎年 15万円（仮） | 迎えた年 ＋10、以後毎年 ＋1 |
| 親孝行 | 30歳以上 | する／しない | 20万円（仮） | する: ＋5 |
| 子どもの成長 | 子どもがいる | なし | 小さな出費（仮: 10万円） | ＋5 |

- 「しない」「見送る」を選んだときは、お金も幸福ポイントも動かない
- 起きやすさは、イベントごとの重みで決める。条件に合わないイベントは選ばれない
- 結婚は、このマスではなく結婚ストップのマスでだけ起きる（3.4）

### 5.2 年齢や状況で自動的に起きるイベント

| イベント | いつ起きるか | プレイヤーの選択 | お金 | 幸福ポイント |
| --- | --- | --- | --- | --- |
| 進学 | 子どもが6・12・15歳になる年 | 公立／私立 | 選んだ学校の教育費が、毎年の年末決算で引かれる（未調査） | なし |
| 大学進学 | 子どもが18歳になる年 | 国公立大学／私立大学／進学しない | 同上 | なし |
| 子どもの独立 | 子どもが22歳になる年（大学に行かなければ18歳） | なし | 生活費と教育費がかからなくなる | ＋5 |
| スポーツ選手の引退 | 33〜37歳のどこか（確率で決まる） | 次の職業を選ぶ（会社員・フリーター・YouTuber） | 次の職業の給料は、その職業の22歳の水準（仮） | なし |
| 給料の見直し | 60歳になる年 | なし | 本人と配偶者の給料が、60歳時点の60%（仮） | なし |
| ゲーム終了 | 65歳の年末決算のあと | なし | なし | 老後の安心ポイントを計算する（9章） |

教育費は、子どもの年齢と公立・私立の選択に応じて、毎年の年末決算で自動的に引かれる。

### 5.3 悩ませる選択にした出来事

「OK」だけだった出来事のうち、次のものは、どちらにも良い面と悪い面がある選択にする（数値は仮）。

| 出来事 | 選択肢 |
| --- | --- |
| 臨時ボーナス（給料の10%） | 使う（幸福 ＋5）／貯める（預金に入れる）／投資に回す（投資方針の配分で買う） |
| 昇進 | 受ける（給料 ＋10%）／断る（自由な時間が増え、幸福 ＋5） |
| 単発の仕事 | 引き受ける（＋30万円、疲れて幸福 −3）／断って休む（幸福 ＋3） |
| 家電の故障 | 安く修理する（−10万円、不便で幸福 −2）／良いものに買い替える（−30万円、幸福 ＋3） |
| 車の修理 | 修理する（−30万円）／車を手放す（＋20万円、不便で幸福 −5） |
| 体調不良 | 病院に行く（−10万円）／我慢する（幸福 −8） |
| 働きすぎ | 休みを取る（給料の5%分が減る、幸福 ＋3）／がんばる（給料の5%分が増える、幸福 −5） |

## 6. 投資

### 6.1 資産の種類

資産は6種類、各1種とする。リスクとリターンの違いを比べながら学べるように、性格の違うものを並べる。

| 資産（架空） | 平均リターン（年、仮） | 値動きの大きさ（仮） | 毎年の収入（仮） | 景気との関係 | 学べること |
| --- | --- | --- | --- | --- | --- |
| 銀行預金 | ０% | なし | 利息 0.3%（金利はニュースで変わる） | なし | 元本が減らない安心感と、増えにくさ |
| 債券 | ０% | ±3% | 利息 1.5% | 不況のときに少し上がる | 安定した利息収入 |
| ゴールド | ＋4% | ±15% | なし | 不況や暴落のときに上がりやすい | 守りの資産、分散の効果 |
| 投資信託（全世界株式インデックス） | ＋6% | ±18% | なし（自動で再投資） | 好況で上がり、不況で下がる | 複利効果、長期・分散投資 |
| 株式（1銘柄） | ＋5% | ±30% | 配当 2.5% | 景気の影響を強く受ける | インカムゲインとキャピタルゲイン、集中投資のリスク |
| 不動産（区分マンション） | 景気による上下 ±5%、さらに古くなるにつれ年 −1% | 小さい | 家賃 5%（経費は家賃の20%） | 不況で空室が出やすい | 家賃収入、ローンを使った投資 |

- 「平均リターン」は価格の値上がり、「毎年の収入」は利息・配当・家賃を指す
- お金はすべて銀行預金として持つ。「現金」という区別はない。給料も支払いも、すべて銀行預金から出し入れする
- 債券・ゴールド・投資信託・株式は、いつでも何度でも売買できる（2.1）。株式は1株単位、それ以外は1万円単位
- 名前は実在の会社や商品に似せない

### 6.2 不動産

不動産は不動産マスに止まったときだけ買える。止まると売り出し中の物件が1つ出て、次の3つから選ぶ。

| 選択 | 内容（仮） |
| --- | --- |
| 自宅として買う | 賃貸から持ち家に変わり、家賃がなくなる。住宅ローンは頭金が価格の10%以上、金利1%、期間は最長35年。家賃収入は生まない。持てる自宅は1つ |
| 投資用に買う | 家賃収入を得る。ローンは頭金が価格の10%以上、金利2%、期間は最長30年。複数持てる |
| 見送る | 何もしない |

- 物件の価格は2,000万円前後（仮）。景気や年によって変わる
- 自宅も投資用も資産として数え、売却はいつでもできる

売り買いのルール（仮）:

| 項目 | ルール |
| --- | --- |
| 売り出し価格 | 相場の価格 × 0.8〜1.2 で物件ごとに変える。割安な物件と割高な物件がある |
| 買うときの諸費用 | 価格の5%（登記や手数料など） |
| 売るときの価格 | その時点の相場の価格（買った値段ではない） |
| 売るときの手数料 | 売却価格の3% |
| ローンが残っている場合 | 売ったお金で、まず残りのローンを返す。足りなければ銀行預金から払う。銀行預金でも足りなければ売れない |
| 自宅を売った場合 | 賃貸に戻り、生活費に家賃分が戻る |

- 買ってすぐ売ると手数料の分だけ損をすること、不況ではローン残高より安くしか売れないことがあることを、体験から学べるようにする
- 空室、修繕、家賃下落などの出来事は「悪い出来事」マスで起きる

### 6.3 投資方針

職業が決まったあと、毎年の余ったお金をどう扱うかの方針を、次の3つから選ぶ。最初に方針を決めて、あとは続けるという長期投資の基本を体験させる。

| 方針 | 内容 |
| --- | --- |
| 自動投資 | 下の3つの型から1つ選ぶ。毎年の余ったお金を、その型どおりに自動で買う |
| 手動で投資設定 | 余ったお金のうち何割を投資に回すかと、債券・ゴールド・投資信託・株式への配分を自分で決める。毎年、その設定どおりに自動で買う |
| 投資しない | 自動では何も買わない。余ったお金はすべて銀行預金に残る。資産運用の画面から、自分で買うのは自由 |

自動投資の型:

| 型 | 投資に回す割合（仮） | 投資に回すお金の配分（仮） |
| --- | --- | --- |
| 安全型 | 30% | 債券70%、ゴールド30% |
| バランス型 | 50% | 投資信託70%、債券20%、ゴールド10% |
| 積極型 | 70% | 投資信託60%、株式40% |

- 年末決算で、方針どおりに自動で買われる。売買しなくても資産形成が進む
- 方針は「資産運用」ボタンからいつでも変えられる
- 不動産は不動産マスでしか買えないので、配分には含めない
- 結果画面で、選んだ方針と、ほかの型だった場合との違いを振り返れるようにする

## 7. 相場の動き

- 毎年の年初に、政治・経済のイベントが1つ起きる。止まったマスに関係なく、その年の相場全体に影響する
  - 例: 利上げ（債券が下がり、預金の利息が上がる）、景気対策（株が上がる）、地政学リスク（ゴールドが上がる）、物価上昇（生活費が上がる）、何も起きない平穏な年
  - 画面には、ニュースと各資産への影響をセットで表示し、「なぜ値段が動いたか」が分かるようにする
- 景気は「好況・通常・不況」の3つの状態を持ち、毎年一定の確率で、またはイベントをきっかけに移り変わる
- 各銘柄の年間リターン ＝ 平均リターン ＋ 景気による上乗せ ＋ 値動きの大きさ × 乱数
- 数年に一度、相場が大きく下がる暴落の年を入れ、長期で持ち続けたときの回復を体験できるようにする
- 乱数には「シード値」を使い、同じシード値なら同じ展開を再現できるようにする（テストと不具合の調査に使う）
- 6.1 の「平均リターン」は、44年間の実際の年平均（複利）がその値になるように、景気とニュースによる上げ下げの偏りを自動で補正する。景気後退や金融危機の下げは好景気の上げより大きいので、補正しないと長期で増えなくなるため
- 物価は毎年1%ずつ上がる。預金だけでは物価の上昇に追いつけないことを体験させる
- 物価の影響を受けるのは生活費だけ。教育費、保育料、イベントの費用、給料、不動産の価格は物価に連動しない（シンプルにするため。イベントの費用などにも反映するかは、将来の検討事項）
- 平均リターンや値動きの大きさは、あとで過去の実績データを調べて調整する

## 8. お金が足りなくなったとき

1. 年末決算で銀行預金がマイナスになったら、まず自動で保有資産を売る（債券 → ゴールド → 投資信託 → 株式の順）。売るか借りるかの選択はない
2. 売っても足りない分だけ、カードローンで自動的に借りる。カードローンに利息はつかない
3. 次の年以降、お金が余ったら、まずカードローンの返済に回す
4. カードローンがある年は、幸福ポイントが毎年 −3。生活費は変わらない
5. 借金は65歳まで残り、純資産のマイナスとして評価される。ゲームオーバーにはしない。最後まで遊んで、借金の怖さも結果に表れるようにする

あわせて、お金を払う選択肢は、その場で銀行預金が足りなければ選べない（例: 預金が10万円なら、海外旅行は選べない）。債券・ゴールド・投資信託・株式は自動では売らないので、使いたいときは「資産運用」画面で自分で売る。ただし、介護のように避けられない出来事で、どの選択肢も払えないときは選べる。

決めた経緯: 段階1の自動シミュレーションで、年15%の利息をつけると借金が何十年も膨らみ続け、10億円を超える例が出た。そのため利息をなくした。利息がないと借金がタダで借りられるお金になり、資産を売らずに借りる方が得になってしまうので、先に必ず資産を売ることにした。

## 9. 結果と評価

純資産だけで評価すると、結婚や子どもが出費でしかなくなり、独身で貯めるのが最強になってしまう。そこで、プロトタイプでは幸福度1つで評価する。

```
幸福度 ＝ 人生の中で得た幸福ポイント ＋ 老後の安心ポイント
```

- **幸福ポイント**: 出来事や選択で増減する。幸福の源は家族、趣味、旅行、仕事のやりがい、健康などに広く散らし、独身でも既婚でも、子どもがいてもいなくても、同じくらい稼げるようにする。借金、失業、病気などでは減る
- **老後の安心ポイント**: 65歳時点の純資産を換算する。増えるほど伸びが鈍る形にする（仮: 100 × log10(1 ＋ 純資産 ÷ 100万円)。1,000万円で約104、1億円で約200）。純資産がマイナスなら、同じ形でマイナスにする
- 純資産 ＝ 銀行預金 ＋ 債券・ゴールド・投資信託・株式・不動産の時価 − ローンなどの借入残高
- 幸福度が動くたびに「家族旅行 ＋5」のように理由を表示する
- 幸福度に応じてランク（S〜D）を表示する。職業は運で決まるので、ランクの基準は**スタート時の職業ごと**に変える。どの職業を引いても、上手に遊べば S を取れるようにする。結果画面では「フリーターの人生で S ランク」のように見せる
- 職業ごとの基準は、自動シミュレーションで、どの職業でも S が約5%、D が約20%になるように決める（仮）
- 画面の上に、「お金の安心」（老後の安心ポイント）と「幸福」（幸福ポイント）を2本のゲージで並べ、どちらも同じくらい大事だと見せる
- 点数の釣り合いは、コンピューターに自動で何千回も遊ばせて確かめる

結果画面では、幸福度とその内訳に加えて、純資産も大きく表示する。あわせて、資産の推移グラフ、資産の内訳、配当や家賃など投資で得た収入の合計、ギャンブルの収支、大きな出来事の年表を見せる。

評価の計算は独立した部品にし、あとで共通ゴール制など別の評価に差し替えられるようにする。

## 11. 実装の方針

- ゲームのルールと計算（`src/game/`）は画面から切り離し、画面なしでテストできるようにする
- 盤面とルーレット（`src/board/`）は独立した部品にし、あとで Phaser に差し替えられるようにする
- 盤面、銘柄、物件、イベント、職業などの数値はデータファイル（`src/data/`）にまとめ、コードを変えずに調整できるようにする
- セーブはブラウザの中に保存する（localStorage）

### 11.1 多言語への備え

今は日本語だけで遊ぶが、あとから他の言語を足せる作りにしておく。

- 画面に出す文字はプログラムの中に直接書かず、言語ごとのファイル（`src/locales/ja.json`）にまとめる。言語を足すときは、ファイルを1つ追加するだけで済むようにする
- 職業、イベント、ニュースなどのデータには文章そのものではなく「文章の番号（キー）」を持たせ、言語ファイルから文章を引く
- 金額や日付の表示は、言語に合わせた書き方（例:「300万円」と「¥3,000,000」）に切り替えられるようにする。ゲーム内の通貨は円のままとする
- 英語などは日本語より文が長くなりやすいので、ボタンや枠は文字の長さに合わせて広がる作りにする
- 設定画面に、言語を切り替える場所を用意できるようにしておく（日本語だけの間は表示しない）
