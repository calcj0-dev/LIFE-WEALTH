# 自動シミュレーションの結果

`npm run simulate` で作成。年数（20・40年）× 職業6 × 投資のしかた3 × 30回 = 1080回 遊ばせた結果。
選択は自動（ギャンブルをする確率30%、家を買えるときに買う確率40%）。
「投資しない」は銀行預金だけ。「積み立てだけ」は、投資信託を毎月おすすめの金額（手取りの1割）で積み立てる。「積み立て＋…」は、さらに年末の取引タイムで、生活費の半年分を残した残りの半分で投資信託を買う。株のマスでは、投資する遊び方のときだけ、ときどき株を買う。

- 結婚した年（中央）: 2年目（早い10% 1年目、遅い10% 6年目）

## テンポ

- ポップアップで止まった回数: 1年あたり平均 6.1回（12ターンのうち。年末のニュースと決算は含まない）
- カードを使った回数: 1年あたり平均 1.9回（自動プレイは、ボーナスマスをねらうときと、手札がいっぱいのときに使う）
