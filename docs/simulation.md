# 自動シミュレーションの結果

`npm run simulate` で作成。年数（20・40年）× 職業6 × 投資のしかた2 × 40回 = 960回 遊ばせた結果。
選択は自動（ギャンブルをする確率30%、家を買えるときに買う確率40%）。
「投資しない」は銀行預金だけ。「余ったお金の半分を投資信託に」は、年末に生活費の半年分を残し、残りの半分で投資信託を買う（取引タイムは次の段階で作るので、ここでは自動で買わせている）。
